# COSC 1437 Review

1. Fork this repository and open your fork in a Codespace.
2. Complete the methods in `problems/`. Do not change the method headers.
3. Check your work in the terminal:

```
./check        # every problem
./check 6      # only problem 6
```

Problems 11 to 15 must use recursion.

## Submit

1. Push your work: `git add . && git commit -m "done" && git push`
2. On your fork's GitHub page, click **Contribute → Open pull request**. Use your full name as the title.
